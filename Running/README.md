# ONE MORE STEP. — GO BEYOND YOUR LIMITS.

واجهة عربية ثابتة للجريات والحجوزات والمحادثات ومقاطع المجتمع، مبنية على Supabase Auth وPostgreSQL وStorage.

## إعداد Supabase

- لمشروع جديد: نفّذ `schema.sql` كاملًا في SQL Editor.
- للمشروع الحالي: نفّذ `supabase-migration.sql` مرة واحدة. يضيف تاريخ الميلاد ورقم الهاتف الاختياري وصورة الحساب، ويوحّد دور العضو إلى `member`، ويُبقي أدوار الإدارة والبيانات الموجودة، ويضيف تخزين المقاطع وصور الحساب والجريات وسياسات RLS.
- بعد دمج ميزة صور مرسلي المحادثة، أعد تشغيل `supabase-migration.sql` المحدّث في SQL Editor. يضيف دالة آمنة لعرض اسم وصورة المشاركين في الجَرية نفسها، ويسمح بإنشاء رابط مؤقت للصورة لهم فقط؛ لا يفتح بيانات البريد أو الهاتف.
- بعد دمج لوحة الإدارة المحدّثة، أعد تشغيل `supabase-migration.sql` في SQL Editor ليظهر العدد الإجمالي للتسجيلات والحضور الآني للمديرين. البريد والهاتف وتاريخ الميلاد يظلون للمالك فقط.
- إذا نجح رفع الصورة لكن فشل حفظها في الحساب، نفّذ `profile-update-policy-migration.sql` في SQL Editor؛ يعيد سياسة تحديث صف العضو نفسه فقط، مع إبقاء قيود الأعمدة ومنع تغيير الدور.
- دالة المالك في `supabase-migration.sql` و`owner-phone-migration.sql` تعيد تاريخ الميلاد من ملف المستخدم، مع الرجوع إلى بيانات التسجيل القديمة عند الحاجة. أعد تشغيل migration المحدّث لإظهار الأعمار المسجلة بالفعل.
- تأكد من تفعيل Email في Authentication. تأكيد البريد يظل مفعّلًا، ويُنشأ الملف الشخصي من trigger `on_auth_user_created` حتى عند انتظار التأكيد.
- في Authentication > URL Configuration أضف عنوان الموقع المنشور إلى Site URL وRedirect URLs.
- بريد Supabase الافتراضي محدود ومناسب للتجربة؛ عند تعثر رسائل التأكيد راجع Auth Logs وحدود الإرسال، واضبط SMTP مخصصًا موثوقًا ووثّق نطاق المرسل (SPF/DKIM/DMARC) للإنتاج.
- يحتوي `app.js` على Project URL ومفتاح publishable فقط. لا تضف `service_role` أو مفاتيح سرية إلى ملفات المتصفح.

بعد تطبيق migration، يمكن جعل حساب موجود مديرًا من SQL Editor بعد التحقق من UUID:

```sql
update public.profiles set role = 'admin' where id = 'YOUR_AUTH_USER_UUID';
```

لا يمكن ترقية الحساب من واجهة الموقع أو بيانات التسجيل.

لترقية حساب موثوق إلى مالك، استخدم بريد الحساب بدلًا من UUID في SQL Editor:

```sql
UPDATE public.profiles p
SET role = 'owner'
FROM auth.users u
WHERE p.id = u.id AND lower(u.email) = lower('YOUR_LOGIN_EMAIL');
```

نفّذ الترقية الأولية للمالك مرة واحدة من SQL Editor. بعدها يستطيع المالك إضافة عدة مديرين أو مالكين من لوحة الإدارة؛ يمنع النظام إزالة دور آخر مالك أو تخفيض المالك الوحيد. لا تسمح واجهة التسجيل باختيار أي دور إداري. إذا استمر خطأ التسجيل، شغّل الاستعلامات الآمنة للقراءة فقط في `supabase-diagnostics.sql` وأرسل النتائج؛ فهي تكشف كل triggers الفعلية على `auth.users` والأعمدة والقيود والسياسات.

## النشر على Vercel

## Sentry وPostHog

- Sentry مربوط بمشروع `onemorestep/one-more-step`، مع مراقبة الأخطاء والأداء وتنقية روابط الطلب من query/hash وعدم إرسال بيانات المستخدم الافتراضية.
- PostHog مضبوط على مشروع US Cloud. المفتاح الموجود في `posthog-config.js` هو **Project API Key** مخصص للواجهة الأمامية؛ لا تستبدله بـPersonal API Key أو مفتاح سري.
- يبدأ PostHog جمع التحليلات تلقائيًا بعد إضافة مفتاح المشروع. autocapture وSession Replay معطلان، ولا نرسل البريد أو الاسم أو محتوى النماذج. الأحداث تقتصر على مشاهدات الصفحات ونجاح التسجيل/الدخول/الحجز.

## رابط الموقع على GitHub Pages

بعد دمج التعديل، افتح Settings > Pages في المستودع واختر GitHub Actions كمصدر النشر. ينشر workflow مجلد `Running/`، والرابط المتوقع هو `https://yousefughh.github.io/RUN/`. أضف هذا الرابط إلى Supabase Authentication > URL Configuration ضمن Site URL وRedirect URLs حتى تعمل روابط تأكيد البريد على الهواتف.

## المقاطع

الصور والفيديوهات حتى 50 MiB تُرفع إلى bucket خاص. أعضاء الموقع يشاهدون مقاطعهم وحالاتها؛ الجمهور يحصل على رابط موقّع للمقاطع المقبولة فقط. القبول والرفض وقائمة المستخدمين متاحة للمدير عبر لوحة الإدارة، وتُفرض الصلاحيات في PostgreSQL وStorage RLS.

يمكن لكل عضو رفع صورة حساب بصيغة JPG أو PNG أو WebP حتى 5 MiB من صفحة الحساب. تُخزّن الصور في bucket خاص وتظهر عبر روابط موقّتة؛ بيانات الملف الشخصي لا يقرأها إلا صاحب الحساب والمديرون.

يمكن للأدمن رفع صورة JPG أو PNG أو WebP حتى 5 MiB عند إنشاء جَرية. تُخزّن في bucket عام مستقل، ولا يُسمح بالرفع أو الحذف إلا للأدمن. يظل إدخال رابط صورة متاحًا كخيار بديل.

شغّل فحوصات المصدر عبر `node --test tests/*.test.mjs`. تحقق من إعدادات Supabase Auth وRLS وStorage وعناوين إعادة التوجيه في بيئتك قبل النشر. لم يتمكن هذا التعديل من الاتصال بقاعدة Supabase المنشورة أو تشغيل التسجيل الفعلي.
